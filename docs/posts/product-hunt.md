# Product Hunt 描述

---

**Slogan（≤80 字符）：**
Build AI-powered workflows visually. Self-hosted, open-source, .NET 8 + Vue 3.

---

**Long Description（≤400 字符）：**
JuggleNet6 is a self-hosted, low-code workflow orchestration platform with AI capabilities. Design flows visually with 14 node types — HTTP calls, conditionals, loops, SQL, code scripts and more. Let AI generate your workflow from a natural language description. Run AI agents with tool calling, image generation and video generation. Features a built-in marketplace, multi-tenant isolation, report designer and monitoring dashboard. One Docker command to deploy. MIT licensed.
